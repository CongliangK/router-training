## 历史服务记录与现在的契约
当晚记录：server.py --run real-history-v3c --port 19948，/health ready:true，
两条人工路由检查符合预期。这仅说明当时服务可运行，不证明生产质量，
本文件也不核验服务目前是否仍在运行。

schema version 2 默认 `--mode diagnostic`，所有建议仅供诊断。
`/health` 和 `/route` 分别报告服务 `mode`、`quality_gate_mode`、
`quality_gate_status`、`execution_allowed` 与 `advisory_only`；非空
recommendation 内也带许可字段。只有显式 execution 模式、对应 gate
严格为布尔 `passed: true` 且 `mode: qualified`、并有授权建议时才允许执行。
v3c 的 shadow gate 在 execution 模式下返回 HTTP 503，不返回可执行建议。
ready、建议存在、历史服务切换均不能代替这项检查。

本次更正只改公开文档与服务契约，不修改归档 gate，不切换或重启任何服务。
